# Paint Studio

A lightweight browser-based painting tool — no dependencies, no build step. Just open `index.html`.

## Features

- Brush and eraser with adjustable size (1–60 px)
- Shape tools: line, rectangle, ellipse, and background fill
- Color picker plus a 12-color quick palette
- Undo (up to 30 steps), clear canvas, export as PNG
- Touch support for tablets/phones
- Keyboard shortcuts: `B` brush, `E` eraser, `L` line, `R` rect, `C` ellipse, `F` fill, `Ctrl+Z` undo

## Usage

Open `index.html` in any modern browser, or host it anywhere static (e.g. GitHub Pages).
